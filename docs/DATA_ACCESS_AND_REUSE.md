# Data access and reuse

This repository publishes research software and aggregate evidence only.

Excluded: participant-level physiological files and labels, raw interaction logs (which may contain IP addresses/account metadata), author emails and supplementary attachments, MP3/WAV/EDF files, model pickles, feature caches, signed URLs, API credentials, and local absolute-path protocol snapshots.

Obtain HKU956 directly from https://doi.org/10.25442/hku.21080821 and cite https://doi.org/10.3390/app12189354. The dataset's README specifies CC BY-NC 4.0. Verify the current distribution and terms before reuse. Do not assume dataset permissions cover audio or author-supplied supplementary files. Download only permitted tracks via their IDs using your own Jamendo read-only client ID, set locally as `JAMENDO_CLIENT_ID`; never commit its value.

The original project used the verified v4 archive. The supplied downloader queries the Figshare article metadata and checks its provided MD5; future article revisions may differ, so exact reproduction requires matching versions and provenance.

This project has not selected an open-source license for its own code. No third-party license is extended to the whole repository. Public access permits review but does not itself establish an open-source reuse grant. Select an appropriate code license with the project owner before broader reuse.
